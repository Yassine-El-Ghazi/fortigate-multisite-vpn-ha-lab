# Security

This repository contains only material from a controlled virtual lab.

## Sanitization

The public repository intentionally excludes:

- VPN pre-shared keys;
- HA passwords;
- FortiGate serial numbers and licensing identifiers;
- raw PCAPNG files;
- CBI internal/customer data;
- proprietary FortiGate VM images or other vendor software.

If you find a value that appears to be a real credential or sensitive identifier, please report it privately to the repository owner rather than opening a public issue.

## Responsible use

The configurations and troubleshooting notes are provided for authorized lab and educational use. They are not a production security baseline.
