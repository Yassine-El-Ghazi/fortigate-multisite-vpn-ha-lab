# Public evidence policy

The project was validated with screenshots, command output, and packet captures during the lab. This public repository publishes only a small, reviewed subset of that material.

## Published

- sanitized FortiGate, router, and switch configurations;
- architecture, troubleshooting, and validation documentation;
- selected screenshots used to demonstrate topology, VPN state, routing, RDP/ESP validation, and HA failover;
- reproducible verification commands and acceptance criteria.

The selected screenshots were re-encoded before publication to remove ancillary image metadata. They contain lab-only addressing and device labels, not production CBI or customer infrastructure.

## Intentionally excluded

- raw `.pcap` / `.pcapng` captures;
- original EVE-NG lab exports and VM images;
- screenshots containing unnecessary device identifiers, serial/licensing data, or other environment metadata;
- credentials, VPN PSKs, HA passwords, tokens, or private keys.

The original validation material remains outside this public portfolio repository.
